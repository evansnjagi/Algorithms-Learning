# Algorithms-Learning
Problem sets and solutions

**Algorithm: ** A set of instructions executed to solve a particular problem. More precisely in 'programming': we can say, an algorithm is set of rules written explicitly telling the computer what to do when solving a particular problem.

There are two most important concepts to consider when evaluation an algorithm and they are:
 - Efficient: This is the time taken for the entire algorithm to run/be executed
 - Correct: If the algorithm actually solves the problem in hand
